# 🛡️ AI Phishing Detector

An intelligent phishing detection system powered by Machine Learning and Artificial Intelligence that identifies malicious URLs, emails, and suspicious web activity in real time.

---

## 🚀 Overview

Phishing attacks are one of the most common cybersecurity threats today. This project leverages AI/ML techniques to analyze URLs and detect phishing attempts with high accuracy.

The system is designed to:
- Detect malicious phishing websites
- Analyze suspicious URLs
- Improve cybersecurity awareness
- Provide fast and reliable predictions
- Demonstrate practical AI applications in cybersecurity

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/kushalram0712/AI-phishing-detector.git
```

Navigate into the project directory:

```bash
cd AI-phishing-detector
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

---

## 📊 How It Works

1. User enters a URL
2. The system extracts important features
3. The ML model analyzes the URL patterns
4. AI predicts whether the URL is:
   - ✅ Legitimate
   - ❌ Phishing
